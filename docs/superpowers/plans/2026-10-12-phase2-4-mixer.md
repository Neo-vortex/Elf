# Phase 2.4: Tayloe Mixer and Baseband (Implementation Plan)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `make hw` also builds and checks the mixer and baseband: the FST3253 four-phase Tayloe mixer with its sampling capacitors, two LM4562 instrumentation-amplifier front halves, the anti-alias RC and the CS5361 input. It writes `hardware/characterized/mixer.json` (spec §6) and a netlist, BOM and SVG.

**Architecture:** The LO is a behavioural stimulus (`QuadratureLO`: S0 and S1 square waves a quarter period apart) that drives the FST3253's select pins; the part's model decodes them into four gate drives, with NMOS switches fitted to the datasheet R_on. Transient runs use Gear integration, a 1 ms window and an output grid of 0.25 µs (only baseband is analysed), while the solver step is capped at T_LO/280. One multi-tone run per test frequency gives the baseband response, image rejection and the 2f/3f/5f responses at once (tones on a 3 kHz offset grid, Hann window). A Monte Carlo of sampling-cap mismatch and LO skew gives image rejection; a two-tone run on the mixer core gives IIP3.

**Tech Stack:** Python 3.11+, SKiDL 2.3.0, numpy, matplotlib, pytest, ngspice 45 (batch mode), Graphviz `dot`.

**Spec:** `docs/superpowers/specs/2026-10-12-phase2-frontend-mixer-design.md` (§5 as amended 2026-10-12, §6 `mixer.json`). Parent: `docs/superpowers/specs/2026-10-12-neoradio-hf-receiver-design.md` (§5, §7 rails as amended).

**Branch:** create `phase2-4-mixer` from `main` before Task 1. Do not work on `main`.

## Global Constraints

- FST3253 on 5V_A (VCC 4.0–5.5 V); select inputs TTL, driven 0/3.3 V. `/1OE` = GND, `/2OE` = 5V_A, section 2 unconnected.
- (S1, S0) = 00, 01, 11, 10 → B0, B1, B3, B2; **I = B0 − B3, Q = B1 − B2**; analysis uses z = I − jQ (upper sideband at positive frequency).
- RF node: 100 nF coupling, biased at 2.5 V through 10 kΩ from a 10k/10k divider on 5V_A (10 µF decoupled).
- Sampling caps 5.6 nF C0G, selected to ±1 % of each other. In-amp front half: Rf 2.2 kΩ, Rg 240 Ω. Anti-alias 100 Ω per leg, 2.7 nF C0G differential. CS5361: 7.5 kΩ differential, VQ 2.5 V (1 µF decoupled).
- LM4562 output swing taken as ±1.0 V per pin around mid-supply at 5 V; full scale = min(ADC 1.13 × 5 / 2 = 2.825 V, op-amp 2.0 V) differential peak.
- Transient: settle 30 µs, window 1 ms, output step 0.25 µs, max solver step T_LO/280, `.options reltol=1e-4 method=gear`; `.save` only the four observed nodes.
- Test tones at −40 dBm on baseband offsets ±(3 … 60) kHz on a 3 kHz grid; harmonic test tones at 2·LO + 9 kHz, 3·LO + 18 kHz, 5·LO + 27 kHz.
- Targets (spec §5): flatness within ±0.5 dB of the mean across ±40 kHz (every test point); 3f and 5f within 1 dB of 20·log(1/3) and 20·log(1/5) at test points ≥ 1.7 MHz; mixer-alone 2f reported; system 2f and 3f rejection (filter attenuation at k·f_LO from `bpf_<n>.s2p` + mixer response) ≥ 60 dB on bands 3–10; image rejection 5th percentile ≥ 30 dB (40 Monte Carlo runs per LO path: caps ±1 %, skew ±0.2 ns direct at 14.2 MHz, ±0.5 ns ÷4 at 1.9 MHz); IIP3 ≥ +25 dBm on the mixer core (tones at −15 and −10 dBm, 12 and 21 kHz offsets).
- Test points: geometric band centres (÷4 below 3.2 MHz, direct above) plus 1.9 MHz on ÷4.
- `make test` stays green: 43 C# + 60 sim + hardware (162 before this plan, 173 after). `make hw` grows by roughly 10–15 minutes (about 95 transient runs in parallel).

## Review Focus

1. **The Gray-code decode order** (00, 01, 11, 10 → B0, B1, B3, B2) must reach the right op-amp inputs; swapping B2/B3 still "works" but turns image rejection into image acceptance. → Task 3 `test_block_wires_gray_code_phases_to_i_and_q`; Task 4 `test_multitone_response_at_20m` (3f lands on the lower sideband, image rejection > 50 dB).
2. **A DC operating point with the LO frozen** leaves three sampling caps floating; a check that read op-amp outputs from `op` would see a saturated amplifier. → Task 3 `test_bias_point_is_mid_supply` (only the bias node and B0 at DC) and Task 4 (DC offset < 50 mV from the transient).
3. **An IMD3 reading that is a measurement floor** (constant dBc versus level) must not be reported as IIP3. → Task 4 reports the IMD3 slope; `make hw` shows ≈ 2.0 dB/dB.
4. **Full scale must come from the op-amp swing, not the ADC**, or the twin clips 3 dB too late. → Task 4 `test_full_scale_is_set_by_the_opamp_swing`.
5. **The S0/S1 stimulus timing** (S1 a quarter period after S0, skew applied to S1) is the only quadrature source in the model. → Task 1 `test_quadrature_lo_puts_s1_a_quarter_period_after_s0`.

```python
"""Turn a SKiDL circuit into an ngspice deck and simulate it."""
from __future__ import annotations

import math
import re
from dataclasses import dataclass
from pathlib import Path

from neohw.ngspice import run_deck
from neohw.rawfile import Plot


class SpiceError(ValueError):
    """The circuit cannot be turned into a valid deck."""


@dataclass(frozen=True)
class Port:
    """S-parameter port (ngspice `portnum`); its internal z0 is noiseless, so use Source/Load
    for noise."""
    net: object
    number: int
    z0: float = 50.0

    def lines(self) -> list[str]:
        drive = 1 if self.number == 1 else 0
        return [f"VPORT{self.number} {node_name(self.net)} 0 dc 0 ac {drive} "
                f"portnum {self.number} z0 {self.z0:g}"]


@dataclass(frozen=True)
class Source:
    """Signal source with a (noisy) series resistor. `tones` are (frequency Hz, available
    power dBm) sine generators for transient analyses; the first stage also carries `ac 1`."""
    net: object
    name: str = "in"
    z0: float = 50.0
    tones: tuple[tuple[float, float], ...] = ()

    @property
    def vname(self) -> str:
        return f"VS_{self.name}0"

    def lines(self) -> list[str]:
        out, prev = [], "0"
        for k, tone in enumerate(self.tones or ((None, None),)):
            nxt = f"s_{self.name}{k}"
            sine = ""
            if tone[0] is not None:
                amp = 2 * math.sqrt(2 * self.z0 * 1e-3 * 10 ** (tone[1] / 10))   # open-circuit peak
                sine = f" sin(0 {amp:.9g} {tone[0]:.9g})"
            out.append(f"VS_{self.name}{k} {nxt} {prev} dc 0{' ac 1' if k == 0 else ''}{sine}")
            prev = nxt
        out.append(f"RS_{self.name} {prev} {node_name(self.net)} {self.z0:g}")
        return out


@dataclass(frozen=True)
class QuadratureLO:
    """Two 50 % square waves driving the mixer selects: S0 at f_hz, S1 a quarter period later
    (+ skew_s). The FST3253 decodes (S1, S0) = 00, 01, 11, 10 into four 25 % phases."""
    s0: object
    s1: object
    f_hz: float
    skew_s: float = 0.0
    edge_s: float = 1e-9
    high_v: float = 3.3

    @property
    def nets(self) -> tuple:
        return (self.s0, self.s1)

    def lines(self) -> list[str]:
        t = 1 / self.f_hz
        w = t / 2 - self.edge_s
        return [f"VLO_s0 {node_name(self.s0)} 0 dc 0 pulse(0 {self.high_v:g} 0 {self.edge_s:g} {self.edge_s:g} {w:.12g} {t:.12g})",
                f"VLO_s1 {node_name(self.s1)} 0 dc 0 pulse(0 {self.high_v:g} {t / 4 + self.skew_s:.12g} "
                f"{self.edge_s:g} {self.edge_s:g} {w:.12g} {t:.12g})"]


@dataclass(frozen=True)
class Load:
    net: object
    name: str = "out"
    r: float = 50.0

    def lines(self) -> list[str]:
        return [f"RL_{self.name} {node_name(self.net)} 0 {self.r:g}"]


@dataclass(frozen=True)
class Supply:
    net: object
    volts: float
    name: str = "vcc"

    @property
    def vname(self) -> str:
        return f"VSUP_{self.name}"

    def lines(self) -> list[str]:
        return [f"{self.vname} {node_name(self.net)} 0 dc {self.volts:g}"]


@dataclass(frozen=True)
class Ac:
    start_hz: float
    stop_hz: float
    points_per_decade: int = 20

    def command(self) -> str:
        return f"ac dec {self.points_per_decade} {self.start_hz:g} {self.stop_hz:g}"


@dataclass(frozen=True)
class Sp:
    start_hz: float
    stop_hz: float
    points: int = 201
    sweep: str = "lin"

    def command(self) -> str:
        return f"sp {self.sweep} {self.points} {self.start_hz:g} {self.stop_hz:g}"


@dataclass(frozen=True)
class Op:
    def command(self) -> str:
        return "op"


@dataclass(frozen=True)
class Noise:
    """Noise analysis referred to `source` (a Source); results in the noise1 plot."""
    output_net: object
    source: Source
    start_hz: float
    stop_hz: float
    points_per_decade: int = 20

    def command(self) -> str:
        return (f"noise v({node_name(self.output_net)}) {self.source.vname} dec {self.points_per_decade} "
                f"{self.start_hz:g} {self.stop_hz:g}\nsetplot noise1")


@dataclass(frozen=True)
class Tran:
    """Transient saved from `start_s` on a uniform `step_s` grid (`linearize`); the solver's
    internal step is capped at `max_step_s` (default: `step_s`)."""
    step_s: float
    stop_s: float
    start_s: float = 0.0
    max_step_s: float | None = None

    def command(self) -> str:
        return (f"tran {self.step_s:g} {self.stop_s:g} {self.start_s:g} {self.max_step_s or self.step_s:g}"
                f"\nlinearize")


def _canonical(net):
    """One net for a merged group (`a += b` leaves pins on both objects): GND if present,
    otherwise the alphabetically first name."""
    group = list(getattr(net, "nets", None) or [net])
    grounds = [n for n in group if n.name.upper() == "GND"]
    return grounds[0] if grounds else min(group, key=lambda n: n.name)


def node_name(net) -> str:
    net = _canonical(net)
    if net.name.upper() == "GND":
        return "0"
    return re.sub(r"[^a-z0-9_]", "_", net.name.lower())


def _check_nets(circuit, ports: list[Port]) -> None:
    """Reject what KiCad and SPICE would read differently, or a part cut out of the circuit."""
    port_nets = {id(_canonical(n)) for p in ports for n in (p.nets if hasattr(p, "nets") else (p.net,))}
    pins_on: dict[int, int] = {}
    nets: dict[int, object] = {}
    for part in circuit.parts:
        for pin in part.pins:
            if pin.net is not None and pin.name not in getattr(part, "nc_pins", ()):
                net = _canonical(pin.net)
                pins_on[id(net)] = pins_on.get(id(net), 0) + 1
                nets[id(net)] = net
    by_node: dict[str, str] = {}
    for key, net in nets.items():
        node = node_name(net)
        if node in by_node and by_node[node] != net.name:
            raise SpiceError(f"nets {by_node[node]!r} and {net.name!r} map to the same SPICE node {node!r}")
        by_node[node] = net.name
        if pins_on[key] < 2 and key not in port_nets and node != "0":
            raise SpiceError(f"net {net.name!r} has a single connection (dangling part?)")


def to_deck(circuit, title: str, ports: list[Port], analyses: list, extra_lines=(),
            variation: dict[str, float] | None = None) -> tuple[str, list[str]]:
    """`variation` maps a part ref to a value multiplier (Monte Carlo); missing refs use 1."""
    variation = variation or {}
    lines = [title]
    models: list[str] = []
    for part in circuit.parts:
        for model in getattr(part, "spice_models", ()):
            if model not in models:
                models.append(model)
    lines += models
    for part in circuit.parts:
        if not hasattr(part, "spice_lines"):
            raise SpiceError(f"{part.ref} has no SPICE model")
        nodes = {}
        for pin in part.pins:
            if pin.net is None or not pin.is_connected():
                if pin.name in getattr(part, "nc_pins", ()):   # may stay open: private node
                    nodes[pin.name] = f"{part.ref}_{pin.name.lower()}"
                    continue
                raise SpiceError(f"{part.ref} pin {pin.name} is unconnected")
            nodes[pin.name] = node_name(pin.net)
        lines.extend(part.spice_lines(nodes, variation.get(part.ref, 1.0)))
    _check_nets(circuit, ports)
    for port in ports:
        lines += port.lines()
    lines.extend(extra_lines)
    raws = []
    lines += [".control", "set filetype=ascii"]
    for k, analysis in enumerate(analyses):
        raw = f"a{k}.raw"
        lines += [analysis.command(), f"write {raw} all"]
        raws.append(raw)
    lines += [".endc", ".end", ""]
    return "\n".join(lines), raws


def simulate(circuit, title: str, ports: list[Port], analyses: list, keep_dir: Path | None = None) -> list[Plot]:
    deck, raws = to_deck(circuit, title, ports, analyses)
    results = run_deck(deck, raws, keep_dir=keep_dir)
    return [results[r][0] for r in raws]
```

`hardware/models/lm4562.lib`:

```
* LM4562 behavioural macromodel, built from the TI datasheet (SNAS326): gain-bandwidth 55 MHz
* (single pole: 3.456 mS into 10 pF), open-loop gain ~131 dB, input voltage noise 2.7 nV/rtHz
* (a 440 ohm series resistor's thermal noise), 30 kohm / 2 pF differential input.
* Not modelled: slew limit (20 V/us), output swing limit (~1.4 V from each rail at +-15 V, taken
* as +-1.0 V around mid-supply at 5 V and checked on the waveforms), current noise

"""Tayloe mixer and baseband (spec §5): FST3253 four-phase switch, four sampling capacitors,
one LM4562 per channel as the front half of an instrumentation amplifier, anti-alias RC and
the CS5361 input.

The FST3253 decodes (S1, S0) = 00, 01, 11, 10 into B0, B1, B3, B2, so the four LO phases
0/90/180/270° land on B0, B1, B3, B2: I = B0 − B3 and Q = B1 − B2. The RF node is AC-coupled
and biased at 2.5 V (VQ of the CS5361; the in-amp passes it through as the output
common mode). FST3253 and op-amps run from 5V_A (the FST3253 needs 4.0–5.5 V).
"""
from __future__ import annotations

from skidl import Circuit, Net

from neohw import parts
from neohw.blocks import Block

C_SAMPLE = "5.6n"     # 4·(50 + 4) Ω · 5.6 nF -> corner ~130 kHz: ±0.5 dB over ±40 kHz
R_F, R_G = "2.2k", "240"   # in-amp front half: differential gain 1 + 2·Rf/Rg = 19.3 (25.7 dB)
R_AA, C_AA = "100", "2.7n"


def _r(value, a: Net, b: Net) -> None:
    r = parts.resistor(value)
    r[1] += a
    r[2] += b


def _c(value, a: Net, b: Net, note: str = "X7R") -> None:
    c = parts.capacitor(value, note=note)
    c[1] += a
    c[2] += b


def _channel(plus: Net, minus: Net, ain_p: Net, ain_n: Net, name: str, vcc: Net, gnd: Net) -> None:
    u = parts.lm4562_dual()
    n1, n2, o1, o2 = (Net(f"{name}_{x}") for x in ("n1", "n2", "o1", "o2"))
    u["+INA"] += plus
    u["-INA"] += n1
    u["OUTA"] += o1
    u["+INB"] += minus
    u["-INB"] += n2
    u["OUTB"] += o2
    u["V+"] += vcc
    u["V-"] += gnd
    _r(R_F, o1, n1)
    _r(R_F, o2, n2)
    _r(R_G, n1, n2)
    _r(R_AA, o1, ain_p)
    _r(R_AA, o2, ain_n)
    _c(C_AA, ain_p, ain_n, "C0G")


def build() -> Block:
    ckt = Circuit()
    with ckt:
        rf_in, gnd, vcc, s0, s1 = Net("rf_in"), Net("GND"), Net("+5V_A"), Net("lo_s0"), Net("lo_s1")
        a, vb = Net("mix_a"), Net("mix_vb")
        b = [Net(f"mix_b{k}") for k in range(4)]
        ail_p, ail_n, air_p, air_n, vq = (Net(x) for x in ("ain_i_p", "ain_i_n", "ain_q_p", "ain_q_n", "adc_vq"))
        _c("100n", rf_in, a, "X7R coupling")
        _r("10k", vcc, vb)
        _r("10k", vb, gnd)
        _c("10u", vb, gnd, "X5R decoupling")
        _r("10k", vb, a)
        sw = parts.fst3253()
        sw["/1OE"] += gnd
        sw["/2OE"] += vcc
        sw["VCC"] += vcc
        sw["GND"] += gnd
        sw["S0"] += s0
        sw["S1"] += s1
        sw["1A"] += a
        for k in range(4):
            sw[f"1B{k}"] += b[k]
            _c(C_SAMPLE, b[k], gnd, "C0G; select the four to ±1 % of each other with the LCR meter")
        _channel(b[0], b[3], ail_p, ail_n, "bb_i", vcc, gnd)
        _channel(b[1], b[2], air_p, air_n, "bb_q", vcc, gnd)
        adc = parts.cs5361()
        adc["AINL+"] += ail_p
        adc["AINL-"] += ail_n
        adc["AINR+"] += air_p
        adc["AINR-"] += air_n
        adc["VQ"] += vq
        adc["GND"] += gnd
        _c("1u", vq, gnd, "X7R VQ decoupling")
        _c("100n", vcc, gnd, "X7R decoupling")
        _c("10u", vcc, gnd, "X5R decoupling")
    return Block("mixer", ckt, {"rf_in": rf_in, "vcc": vcc, "s0": s0, "s1": s1, "b": tuple(b),
                                "ain_i": (ail_p, ail_n), "ain_q": (air_p, air_n)})
```

stimulus, one multi-tone run per test frequency (band centres; the ÷4 path below 3.2 MHz and at

from dataclasses import dataclass
from pathlib import Path

import numpy as np

from neohw import availability, charfile, export
from neohw.blocks import bpf, mixer
from neohw.checks import BlockResult, CheckResult

# baseband offsets on a 3 kHz grid (Hann window, 1 kHz bins: products stay >= 3 bins apart)
OFFSETS_HZ = (3e3, 12e3, 21e3, 30e3, 39e3, 48e3, 57e3, -6e3, -15e3, -24e3, -33e3, -42e3, -51e3, -60e3)

SETTLE_S, WINDOW_S, OUT_STEP_S = 30e-6, 1e-3, 0.25e-6
STEPS_PER_LO_PERIOD = 280
OPTIONS = ".options reltol=1e-4 method=gear"    # trapezoidal rings on the switched caps
FLATNESS_DB = 0.5
HARMONIC_TOL_DB = 1.0
HARMONIC_MIN_LO_HZ = 1.7e6     # below ~1 MHz the sampling RC is no longer << T_LO (bands 1–2 reported only)
TWO_F_MAX_DBC = -40.0          # mixer alone: reported; gated as system rejection with the filter
SYSTEM_REJ_MIN_DB = 60.0       # filter attenuation at k·LO + mixer k-th harmonic response, bands with a 3f target
IMAGE_MIN_DB = 30.0
IIP3_MIN_DBM = 25.0
MC_RUNS = 40
MC_POINTS = {"direct": 14.2e6, "div4": 1.9e6}
LO_SKEW_S = {"direct": 0.2e-9, "div4": 0.5e-9}   # uniform ±: Si5351 output skew / 74LVC74 flop mismatch
SAMPLE_CAP_TOL = 0.01                             # the four caps are selected to ±1 % (BOM note)
OPAMP_SWING_V = 1.0           # LM4562 at 5 V: ±1 V per output around mid-supply (datasheet ~1.4 V from rails at ±15 V)

@dataclass(frozen=True)
class TestPoint:
    f_lo: float
    path: str


def test_points() -> list[TestPoint]:
    pts = [TestPoint(math.sqrt(lo * hi), "direct" if math.sqrt(lo * hi) >= DIRECT_MIN_HZ else "div4")
           for lo, hi in bpf.BANDS]
    return pts + [TestPoint(1.9e6, "div4")]


def _amp_in(dbm: float) -> float:
    """Voltage amplitude a matched 50 Ω load sees for `dbm` available power."""
    return math.sqrt(2 * 50 * 1e-3 * 10 ** (dbm / 10))


def _deck(blk, f_lo: float, tones, skew: float = 0.0, variation=None, tap: str = "adc"):
    if tap == "adc":
        nodes = [*blk.ports["ain_i"], *blk.ports["ain_q"]]
    else:   # mixer core: I = B0 − B3, Q = B1 − B2
        b = blk.ports["b"]
        nodes = [b[0], b[3], b[1], b[2]]
    names = [node_name(n) for n in nodes]
    deck, raws = to_deck(blk.circuit, f"mixer {f_lo:g}",
                         [Source(blk.ports["rf_in"], "rf", tones=tuple(tones)), Supply(blk.ports["vcc"], 5.0),
                          QuadratureLO(blk.ports["s0"], blk.ports["s1"], f_lo, skew_s=skew)],
                         [Tran(OUT_STEP_S, SETTLE_S + WINDOW_S, SETTLE_S, 1 / f_lo / STEPS_PER_LO_PERIOD)],
                         extra_lines=[OPTIONS, ".save " + " ".join(f"v({x})" for x in names)], variation=variation)
    return deck, raws, names


def _spectrum(res, raws, names):
    d = res[raws[0]][0].data
    t = d["time"].real
    n = int(round(WINDOW_S / OUT_STEP_S))
    m = t >= SETTLE_S - OUT_STEP_S / 2
    v = [d[f"v({x})"].real[m][:n] for x in names]
    i, q = v[0] - v[1], v[2] - v[3]
    z = i - 1j * q                     # upper sideband at positive baseband frequency
    spec = np.fft.fft(z * np.hanning(n)) / (n / 2)
    freqs = np.fft.fftfreq(n, OUT_STEP_S)
    return freqs, spec, i, q


def _bin(freqs, spec, f):
    return spec[int(np.argmin(np.abs(freqs - f)))]


def multitone_tones(f_lo: float):
    tones = [(f_lo + o, TONE_DBM) for o in OFFSETS_HZ]
    tones += [(h * f_lo + o, TONE_DBM) for h, o in HARMONICS.items()]
    return tones


def analyse_multitone(f_lo: float, freqs, spec, i, q) -> dict:
    a = _amp_in(TONE_DBM)
    h = {}
    for o in OFFSETS_HZ:
        h[o] = _bin(freqs, spec, o) / a * np.exp(-2j * np.pi * o * SETTLE_S)
    ref = np.mean([abs(h[o]) for o in OFFSETS_HZ if abs(o) <= FLAT_SPAN_HZ])
    flat = [20 * math.log10(abs(h[o]) / ref) for o in OFFSETS_HZ if abs(o) <= FLAT_SPAN_HZ]
    image = [20 * math.log10(abs(_bin(freqs, spec, o)) / abs(_bin(freqs, spec, -o))) for o in OFFSETS_HZ]
    harm = {}
    for k, o in HARMONICS.items():
        up, lo = _bin(freqs, spec, o), _bin(freqs, spec, -o)
        side = "upper" if abs(up) >= abs(lo) else "lower"
        c = (up if side == "upper" else lo) / a
        harm[k] = {"db": 20 * math.log10(abs(c) / ref), "phase_deg": math.degrees(np.angle(c)), "sideband": side}
    return {"h": h, "ref_gain": ref, "flatness_db": max(abs(x) for x in flat), "image_min_db": min(image),
            "harmonics": harm, "dc_offset_v": (float(i.mean()), float(q.mean()))}


def image_rejection_db(freqs, spec, offset: float = 12e3) -> float:
    return 20 * math.log10(abs(_bin(freqs, spec, offset)) / abs(_bin(freqs, spec, -offset)))


def iip3_dbm(blk=None, f_lo: float = 14.2e6, levels=(-15.0, -10.0)) -> dict:
    blk = blk or mixer.build()
    f1, f2 = 12e3, 21e3                 # products at 3 kHz and 30 kHz
    decks = [_deck(blk, f_lo, [(f_lo + f1, p), (f_lo + f2, p)], tap="core") for p in levels]
    results = run_decks([d for d, _, _ in decks], decks[0][1])
    out = []
    for p, (d, raws, names), res in zip(levels, decks, results):
        freqs, spec, _, _ = _spectrum(res, raws, names)
        fund = (abs(_bin(freqs, spec, f1)) + abs(_bin(freqs, spec, f2))) / 2
        imd = max(abs(_bin(freqs, spec, 2 * f1 - f2)), abs(_bin(freqs, spec, 2 * f2 - f1)))
        dbc = 20 * math.log10(fund / imd)
        out.append({"tone_dbm": p, "imd3_dbc": dbc, "iip3_dbm": p + dbc / 2})
    slope = (out[0]["imd3_dbc"] - out[-1]["imd3_dbc"]) / (levels[-1] - levels[0])   # 2 dB/dB when third-order
    return {"iip3_dbm": out[-1]["iip3_dbm"], "imd3_slope_db_per_db": slope, "runs": out}


def image_monte_carlo(blk, path: str, runs: int) -> list[float]:
    f_lo = MC_POINTS[path]
    caps = sorted(p.ref for p in blk.circuit.parts if p.value == "5.6nF")
    decks = []
    for r in range(runs):
        rng = np.random.default_rng([7, int(f_lo), r])
        var = {ref: 1 + rng.uniform(-SAMPLE_CAP_TOL, SAMPLE_CAP_TOL) for ref in caps}
        skew = rng.uniform(-LO_SKEW_S[path], LO_SKEW_S[path])
        decks.append(_deck(blk, f_lo, [(f_lo + 12e3, TONE_DBM)], skew=skew, variation=var))
    results = run_decks([d for d, _, _ in decks], decks[0][1])
    return [image_rejection_db(*_spectrum(res, raws, names)[:2]) for (_, raws, names), res in zip(decks, results)]


def system_rejection_db(char_dir: Path, band: int, f_lo: float, harmonic: int, mixer_db: float) -> float:
    """Rejection of the k-th LO harmonic response: filter attenuation at k·f_lo (from the
    committed bpf_<band>.s2p) minus the mixer's k-th harmonic response (dB re fundamental)."""
    path = Path(char_dir) / f"bpf_{band}.s2p"
    if not path.exists():
        raise FileNotFoundError(f"{path} is missing: the bpf_bank check must run before the mixer check")
    f, s = read_s2p(path)
    s21_db = np.interp(harmonic * f_lo, f, 20 * np.log10(np.abs(s["21"])))
    s21_lo = np.interp(f_lo, f, 20 * np.log10(np.abs(s["21"])))
    return float(-(s21_db - s21_lo) - mixer_db)


def full_scale_dbm(gain: float) -> float:
    """Input power that drives the ADC (or, first, the op-amp swing) to full scale."""
    v_fs = min(ADC_FS_PEAK_V, 2 * OPAMP_SWING_V)
    a = v_fs / gain
    return 10 * math.log10(a ** 2 / (2 * 50) / 1e-3)


def run(out_dir: Path, char_dir: Path, mc_runs: int = MC_RUNS, points=None) -> BlockResult:
    out_dir, char_dir = Path(out_dir), Path(char_dir)
    blk = mixer.build()
    pts = list(points or test_points())
    decks = [_deck(blk, p.f_lo, multitone_tones(p.f_lo)) for p in pts]
    results = run_decks([d for d, _, _ in decks], decks[0][1])
    per_point = []
    for p, (_, raws, names), res in zip(pts, decks, results):
        per_point.append((p, analyse_multitone(p.f_lo, *_spectrum(res, raws, names))))
    mc = {path: image_monte_carlo(blk, path, mc_runs) for path in MC_POINTS}
    ip3 = iip3_dbm(blk)
    flat = max(r["flatness_db"] for _, r in per_point)
    gated = [r for p, r in per_point if p.f_lo >= HARMONIC_MIN_LO_HZ]
    dev3 = max(abs(r["harmonics"][3]["db"] - 20 * math.log10(1 / 3)) for r in gated)
    dev5 = max(abs(r["harmonics"][5]["db"] - 20 * math.log10(1 / 5)) for r in gated)
    two_f = max(r["harmonics"][2]["db"] for _, r in per_point)
    system = {}
    for band, (p, r) in enumerate(per_point[:len(bpf.BANDS)], 1):
        lo, hi = bpf.BANDS[band - 1]
        if 3 * lo > hi:      # bands with a 3f rejection target (spec §4)
            system[band] = {k: system_rejection_db(char_dir, band, p.f_lo, k, r["harmonics"][k]["db"]) for k in (2, 3)}
    sys2 = min(v[2] for v in system.values())
    sys3 = min(v[3] for v in system.values())
    p5 = {path: float(np.percentile(v, 5)) for path, v in mc.items()}
    nominal = min(per_point, key=lambda pr: abs(pr[0].f_lo - MC_POINTS["direct"]))[1]
    gain = nominal["ref_gain"]
    checks = [
        CheckResult("flatness_max_dev_db", flat, f"≤ {FLATNESS_DB:g}", flat <= FLATNESS_DB),
        CheckResult("third_harmonic_dev_db", dev3, f"≤ {HARMONIC_TOL_DB:g}", dev3 <= HARMONIC_TOL_DB),
        CheckResult("fifth_harmonic_dev_db", dev5, f"≤ {HARMONIC_TOL_DB:g}", dev5 <= HARMONIC_TOL_DB),
        CheckResult("second_harmonic_max_dbc", two_f, f"report (spec {TWO_F_MAX_DBC:g})", True, "dBc"),
        CheckResult("system_2f_rejection_min_db", sys2, f"≥ {SYSTEM_REJ_MIN_DB:g}", sys2 >= SYSTEM_REJ_MIN_DB),
        CheckResult("system_3f_rejection_min_db", sys3, f"≥ {SYSTEM_REJ_MIN_DB:g}", sys3 >= SYSTEM_REJ_MIN_DB),
        CheckResult("image_rejection_p5_direct_db", p5["direct"], f"≥ {IMAGE_MIN_DB:g}", p5["direct"] >= IMAGE_MIN_DB),
        CheckResult("image_rejection_p5_div4_db", p5["div4"], f"≥ {IMAGE_MIN_DB:g}", p5["div4"] >= IMAGE_MIN_DB),
        CheckResult("iip3_dbm", ip3["iip3_dbm"], f"≥ {IIP3_MIN_DBM:g}", ip3["iip3_dbm"] >= IIP3_MIN_DBM, "dBm"),
        CheckResult("imd3_slope_db_per_db", ip3["imd3_slope_db_per_db"], "report (2 = third order)", True, ""),
        CheckResult("conversion_gain_db", 20 * math.log10(gain), "report", True),
        CheckResult("full_scale_input_dbm", full_scale_dbm(gain), "report", True, "dBm"),
    ]
    result = BlockResult("mixer", checks, plots={
        f"{p.f_lo / 1e6:.2f} MHz ({p.path})": (np.array(sorted(r["h"])), np.array(
            [20 * math.log10(abs(r["h"][o])) for o in sorted(r["h"])])) for p, r in per_point})
    data = availability.load()
    h = nominal["h"]
    harmonics = {"1": {"db": 0.0, "phase_deg": 0.0, "sideband": "upper"}}
    harmonics.update({str(k): v for k, v in nominal["harmonics"].items()})
    result.artefacts = {
        "kicad_netlist": export.kicad_netlist(blk.circuit, out_dir / "mixer.net"),
        "bom": export.write_bom(blk.circuit, out_dir / "mixer_bom.csv", data),
        "svg": export.svg_diagram(blk.circuit, out_dir / "mixer.svg"),
        "characterisation": charfile.write(char_dir / "mixer.json", "mixer", "pass" if result.passed else "fail", {
            "conv_gain_db": 20 * math.log10(gain),
            "conv_gain_definition": "per-channel differential amplitude at the ADC pins / matched-source amplitude at rf_in",
            "baseband_response": {"offset_hz": sorted(h), "re": [float(h[o].real / gain) for o in sorted(h)],
                                  "im": [float(h[o].imag / gain) for o in sorted(h)]},
            "harmonic_responses": harmonics,
            "iip3_dbm": ip3["iip3_dbm"],
            "image_rejection_db": {path: {"median": float(np.median(v)), "p5": p5[path], "runs": len(v)}
                                   for path, v in mc.items()},
            "dc_offset_v": list(nominal["dc_offset_v"]),
            "adc_full_scale_dbm": full_scale_dbm(gain),
            "full_scale_limit": "op-amp swing" if 2 * OPAMP_SWING_V < ADC_FS_PEAK_V else "ADC",
            "test_points": [{"f_lo_hz": p.f_lo, "path": p.path, "flatness_db": r["flatness_db"],
                             "image_min_db": r["image_min_db"], "conv_gain_db": 20 * math.log10(r["ref_gain"]),
                             "harmonics": r["harmonics"]} for p, r in per_point],
            "system_rejection_db": {str(b): {str(k): v for k, v in rej.items()} for b, rej in system.items()},
            "checks": [c.__dict__ for c in checks]}),
    }
    return result
